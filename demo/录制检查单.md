# 录制检查单

## 提前一天

- [ ] 确定使用两台电脑、虚拟机，还是本机练习模式。
- [ ] 两台电脑都接电源，关闭自动睡眠和系统更新提醒。
- [ ] 被控端准备一个无隐私内容的桌面和空白记事本。
- [ ] 控制端确认能连接被控端的局域网 IPv4 地址与端口 `9999`。
- [ ] 完整排练两遍，单次不超过 4 分 40 秒。
- [ ] 不在画面中展示个人文件、聊天、邮箱、令牌、公网地址或密码。

## 开录前 10 分钟

- [ ] 清理桌面，只保留仓库、架构图、代码编辑器和客户端。
- [ ] 代码编辑器提前打开四个文件：`common/packet.h`、`windows/server.cpp`、`windows/qt_client/connection_window.cpp`、`windows/qt_client/remote_screen_widget.cpp`。
- [ ] 打开 `demo/architecture.svg`，设置合适缩放。
- [ ] 被控端打开空白记事本，准备输入 `remote-control-demo`。
- [ ] 关闭通知、聊天软件弹窗与浏览器隐私页面。
- [ ] 麦克风试录 10 秒，确认音量不过小、没有爆音。
- [ ] 录制分辨率至少 1920×1080；鼠标指针可见。

## 开录前连接检查

- [ ] 服务端显示正在监听 `9999`。
- [ ] Qt 客户端状态为 Connected。
- [ ] 远端画面持续更新，不是静止截图。
- [ ] 客户端窗口缩放后画面比例正常。
- [ ] 鼠标移动、点击、英文输入、Backspace、Enter 均有效。
- [ ] 输入开关关闭时不能控制，重新打开后恢复。
- [ ] 客户端状态区能看到帧信息和心跳往返时间。

## 正式录制

- [ ] 前 30 秒说清“为什么做”和“是什么”。
- [ ] 架构说明不超过 35 秒。
- [ ] 实际连接与操作占约 70 秒。
- [ ] 最花时间的功能说清“分帧组帧”和“只保留最新帧”。
- [ ] 最细致的地方说清“黑边坐标映射”和“释放按下状态”。
- [ ] 主动说明遗憾与下一步，不夸大为生产级软件。
- [ ] 总时长控制在 5 分钟以内。

## 录完立即复查

- [ ] 从头到尾播放一遍，声音与画面同步。
- [ ] 没有黑屏、无限套屏、通知弹窗或隐私泄露。
- [ ] 关键代码字体能看清，鼠标动作能跟上讲解。
- [ ] 文件可正常播放，时长不超过题目要求。
- [ ] 保留原始录屏，再导出一份提交版，避免直接覆盖。

## 录制失败时的取舍顺序

1. 跨机器连接不稳：改为本机连接，缩小客户端窗口并避开无限套屏区域。
2. 输入偶发失灵：保留画面连接演示，转而展示输入协议和已验证测试记录。
3. 时间超出：先删重连现场操作，再压缩代码滚动；不要删“动机、难点、细节、遗憾”四项。
4. 临场说错：停两秒重新说完整句，后期剪掉错误段，不要边道歉边继续。
